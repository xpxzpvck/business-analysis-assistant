# Review deliverable

Read docs/STATUS.md, relevant docs/REQUIREMENTS.md rows and changed artifacts. For submission read docs/SUBMISSION.md; for NLP changes inspect evaluation records.

Inspect git status, tracked diff and new files. Check scope, requirement evidence, behavior risks, secrets and documentation. Use AGENTS.md commands; environment checks are not application tests.

For applicable runtime outputs check requirement links, one accountable role per RACI activity and confirmed/assumed separation. Require evaluation for every actual component at submission. Missing code or runs means not run, not pass.

Output actionable findings with location, impact and required verification, then evidence and unverified items. Separate increment readiness from overall application readiness. Fix authorized routine issues and repeat affected checks. Update STATUS and material approved decisions. Do not publish or deploy as part of review.
