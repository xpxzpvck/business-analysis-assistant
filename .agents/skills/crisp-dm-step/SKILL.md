# CRISP-DM step

Read docs/STATUS.md and the relevant requirements and CRISP-DM phase table in docs/REQUIREMENTS.md. Read docs/ARCHITECTURE.md or evals/PLAN.md only when relevant to the selected phase.

Identify the requested phase and whether the task is planning or review. If unspecified, infer it from the recorded state and state the choice.

Produce a compact phase note:
- goal and requirement IDs;
- available evidence and missing inputs;
- smallest next artifact and steps;
- exit criteria and checks;
- open decisions and next phase.

During review, map exit criteria to actual evidence. A plan or template does not prove completion. For Data understanding, research existing datasets before generating synthetic data. Keep unresolved choices marked as proposals.

Update docs/STATUS.md with work actually performed. Record material approved decisions in the decision log in docs/ARCHITECTURE.md.

If implementation is requested and already authorized, continue the agreed task. This skill does not authorize scope or architecture changes.
